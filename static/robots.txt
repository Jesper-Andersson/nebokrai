# Everything may be crawled except what is not a page to read: the API, the
# report form (it takes parameters, so it has endless addresses) and the
# sign-in addresses. src/hooks.server.ts also marks these and /saved "noindex".
# /review is a visitor's own flashcards: the same for every crawler, and empty.
# /import reads a file the visitor chooses: there is nothing on it to read.
# A search (/?q=kava) is not a page either: every query is an address, and
# each one fetched is a search of the database.
# offline.html is what the installed app shows without a connection; it says
# "noindex" itself. Cloudflare serves it at /offline, and the line below
# covers both addresses.
# /dev/ is pages for building the site; here they answer 404.
